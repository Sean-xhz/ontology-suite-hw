# 结构化输入 → 29 句话描述集通用映射方法（entry (b) 快速通道）

> **适用**：输入资料已是**统一章节模板的结构化文档**（产品大纲模板、条款模板、商品清单模板等——业务侧已完成文档标准化）时，S1 萃取从「多模态解析+三维访谈」降级为「**模板章节 → 描述集分节的机械映射**」，冷启动成本大幅降低。
> **来源与裁定史**：见本 skill `CHANGELOG.md`（1.1.0 生产级 run 复盘资产化 / 1.3.0 M2 重写为通用方法，原特定模板映射表降为附录示例）；本文件只登记当前有效方法。
> **纪律**：本指引只登记**方法与映射骨架**，零业务内容；示例中的章节名按输入模板实际名称替换。

## 一、适用判定（S0 准入时检查）

| 判定项 | 通过标准 |
|---|---|
| 模板统一性 | 输入文档集共享同一章节模板（章节数/名/序基本一致，允许选填节缺失） |
| 粒度充分性 | 章节内含字段级信息（参数/枚举/清单），非纯叙述文 |
| 覆盖度 | 待建模对象集的大部分成员有对应文档（覆盖缺口须显式登记，缺失对象不补造） |

任一不满足 → 回退入口 (a) 全量 S1 三维访谈萃取。

## 二、通用映射方法（四步，与具体模板无关）

映射的判据是**章节的内容特征**，不是章节名——任何统一模板都按以下四步建立「章节 → 描述集分节」映射表：

### 第 1 步 · 章节语义识别

逐章节按内容特征归入语义类别（一个章节可命中多类，拆条分派）：

| 内容特征 | 语义类别 | 描述集目标分节 |
|---|---|---|
| 定义性内容（对象是什么/有哪些属性/分类与枚举） | 对象与概念 | 1 对象描述类 |
| 关联性内容（谁与谁有关系、方向、基数） | 对象关系 | 1 对象描述类（1.3 关联位） |
| 判断性内容（若什么条件则什么结论/阈值/禁入条款） | 控制规则 | 4 控制规则类（主战场） |
| 流程性内容（步骤顺序/操作/通道） | 任务与流程 | 5 流程活动类【扩展位】 |
| 权限性内容（谁可自主/须确认/禁止做什么） | 权限管控 | 6 权限管控类【扩展位】 |
| 术语性内容（同义词/口语说法/问答对） | 术语 | 3 术语类 |
| 例外性内容（特殊客群/特殊状态/跨对象口径） | 例外与边界 | 2 分层约束类（层级/互斥断言）/ 4 控制规则类（例外条件） |
| 清单参数性内容（大批量枚举值/区域列表/日期表） | 数据层候选 | **不进本体**——登记接口契约（见 §四数据层分界） |
| 数值参数性内容（费率/额度/分值等商务参数） | 敏感登记 | 只登记属性位与结构语义，参数值按 sensitivity-rules 口径处理 |

> 注：7 CRUD 查询类与 8 目标评估类不由章节映射产出——查询模板随规则消费场景补写；目标评估按「+1」必填口径由 G1 人工补全。

### 第 2 步 · 建立本次 run 的映射表

把第 1 步的识别结果固化为「输入章节 → 描述集目标分节 → 映射要点」三列表（附录示例为一份成品参照）。映射要点须写明：该章节产出哪类描述句、参数如何处置（照录/结构位/敏感登记）、缺失如何登记。

### 第 3 步 · 逐份执行机械映射

按映射表把各文档章节内容分派到描述集分节；同一分节跨文档合并时**冲突显式登记**（不同文档对同一规则口径不一致→待确认项，不静默择一）。控制规则章节逐条拆：硬门槛→R 族规则（阈值/维度/时间窗三要素齐备才可编译）；禁入条款→负向规则；**参数值照录不模糊化**，无值登记待确认。

### 第 4 步 · 缺口信号分级登记

映射中发现的新实体轴/新枚举值/新机构类型→按「结构级/词表级/参数级」分级登记（基线迭代输入清单形态）；选填节缺失→登记「未提供，待确认」而非「无此语义」。

## 三、执行步骤（S1' 机械映射档全流程）

1. **模板盘点**：读 1-2 份样本确认章节模板与选填节分布；登记覆盖度（哪些对象缺哪些节）。
2. **建映射表**：按 §二第 1-2 步产出本次 run 的章节映射表（新模板首次使用时的唯一新增成本；同模板复用时直接继承）。
3. **逐份映射**：按 §二第 3 步执行。
4. **高频名词登记**（SKILL.md S1 机械步骤同样适用）：跨文档 ≥3 次名词→候选实体清单（建/不建+理由）。
5. **缺口信号分级**：按 §二第 4 步执行。
6. **产出**：29 句话描述集草稿+术语词典草稿+缺口信号清单 → 正常进 S2/G1（**G1 人工闸门不降级**——机械映射降低的是萃取成本，不是业务确认必要性）。

## 四、边界与反模式

- **禁止**：因模板统一而跳过 G1；把章节标题直接当类名（须过术语词典归一）；把选填节缺失当「无此语义」（缺失=未提供，登记待确认）。
- **数据层/本体层分界不变**：清单运算（区域列表/行业列表/日期差）与分值计算仍归数据层，本体只给结构位+受控词表（映射时逐条判断，参照 checklist-visual-review 消费位问句）。
- 本指引与三维访谈协议（`methodology-core.md` §1）互补不替代：混合输入（部分标准模板+部分原始资料）时，标准模板部分走本指引、其余走三维访谈，S0 裁剪登记注明双通道。

## 附录 · 示例：某产品类十一节大纲模板映射骨架

> 以下为一份金融域产品大纲模板的成品映射表**示例**（章节名与要点均中性化），演示 §二方法的产出形态；各域按同构方法建立自己的映射表，**不要直接套用本表章节名**。

| 输入章节 | 描述集目标分节 | 映射要点 |
|---|---|---|
| ①产品基本信息 | 1 对象描述类 / 4 控制规则类（标识与状态） | 产品编号→唯一标识要素；上下架状态→状态类轴；合作机构→机构类+提供关系 |
| ②产品介绍 | 1 对象描述类 / 2 分层约束类（层级归属） | 服务主体类型→客户类分叉；产品定位→类型叶类归属判断 |
| ③展业区域 | 1 对象描述类（区域实体/属性）/ 4 控制规则类 | 区域清单=**数据层**（清单运算不进本体，登记接口契约）；区域×状态档位若有→受控词表评估 |
| ④准入与规则 | 4 控制规则类（主战场） | 逐条拆：硬门槛→R 族规则（阈值/维度/时间窗三要素齐备才可编译）；禁入条款→负向规则；**参数值照录不模糊化**，无值登记待确认 |
| ⑤额度与期限 | 1 对象描述类（属性位）/ 4 控制规则类 | 额度/期限区间→数据属性位+区间约束（结构位入本体，值=实例层数据） |
| ⑥费率费用 | 1 对象描述类（属性位） | **敏感登记**：只登记属性位与结构语义，参数值按 sensitivity-rules 口径处理（商务参数不转录） |
| ⑦申请流程 | 5 流程活动类【扩展位】 | 流程步骤→md 结构化描述（BPMN 扩展位降级口径）；进件通道差异→通道属性 |
| ⑧增信方式 | 1 对象描述类（担保类/增信类） | 增信方式枚举→受控词表；新形态→类型轴缺口信号登记 |
| ⑨软性偏好（选填） | 4 控制规则类（软规则族） | 命中越多越优质=软因子规则（scoringWeight 结构位，分值=应用层）；缺失节→登记「无软规则」而非留空 |
| ⑩其他说明 | 4 控制规则类（例外条款与全局公理） | 特殊客群/特殊状态→例外条款；跨产品口径→全局公理候选 |
| ⑪QA | 3 术语类 | QA 对=术语词典天然素材（问题侧→同义词/口语表述，答案侧→规则语义复核）；上游已标准化的 FAQ 无需再拆解，转为**入库时校验**位 |
