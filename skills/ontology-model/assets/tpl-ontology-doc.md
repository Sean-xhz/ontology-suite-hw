# 建模方案文档模板（run 产物 `建模方案.md`）

> **用途**：S2/S3 阶段组装、随管线滚动更新的 run 产物模板（8 件套之 `建模方案.md`）——本体的可读性主文档，与 ontology.ttl 互为表里（ttl 是机器形态，本文档是评审与交接形态）。
> **结构权威**：四层组织法、各层要素模板（实体八要素/关系七要素/公理六要素）、切片四元组、处置档定义的**表格骨架与要素定义见 `references/structure-patterns.md`，本模板只定文档章节顺序与填写要求——不复制内容，防止跨文件漂移**。
> **更新时序**：S2 建骨架填一、二、三层草稿 → S3 与 ttl 同步定稿 → S4 修订随博弈轮次更新 → S6 补验收结论 → 交付前补版本纪律节。
