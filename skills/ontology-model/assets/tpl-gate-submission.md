# 闸门呈报件模板（G1/G2/G3 通用）

> **用法**：复制对应节到 `过程/02 闸门/<闸门>_<YYYYMMDD>_呈报.md` 填写；人工裁定后按标准格式回填「裁定登记」节。
> **设计原则**：三道闸门呈报结构可预期——评审人不读会话上下文即可定位「审什么 / 怎么裁 / 结论回填在哪」。
> 配例一律虚构中性；本模板不含任何真实业务数据。
