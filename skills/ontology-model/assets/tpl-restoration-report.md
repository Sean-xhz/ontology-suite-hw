## 0. 对照口径与方法

**两侧形态差异（先声明，防止口径错位）**：

| | 对照基准 | 盲测重建 |
|---|---|---|
| 载体 | [md 设计方案 / 其他人工方案形态] | W3C Turtle 本体（reasoner 可执行） |
| 范围 | [基准覆盖范围，如全生命周期] | [重建声明范围，如核心推理切片] |
| 公理观 | [基准公理形态，如数据质量门禁条款] | OWL 逻辑公理（disjoint/equivalentClass/基数等，reasoner 消费） |
| 构件基线 | [N 实体/N 关系/N 公理/N 规则组/N 切片 = **M 对照单元**] | [N 类/N 对象属性/N 数据属性/N SWRL/N Concept] |

**判定三档**：
- ✅ 还原：语义对应成立，允许 W3C 化变形（含形式化深化）
- ◐ 部分或降级还原：降为数据属性、登记缺口、裁量至应用层——**须有登记位支撑**（编译缺口/G2 裁定/exempt 登记）
- ✗ 未还原，分三类：
  - 范围外裁量：S0 裁剪登记 / 描述集「明确不做」覆盖（非能力缺陷）
  - **范围内漏检（真漏检）**：输入资料含信号但未重建
  - 两侧一致放弃：裁量重合（计 ✅）

**还原率双口径**：全口径 = 加权得分 / M；范围口径 = 加权得分 / (M − 范围外单元数)。✅=1，◐=0.5，✗=0。
