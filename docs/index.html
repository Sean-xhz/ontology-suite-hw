三件套管线

1

ontology-model

「7+1」29 句话描述集 → W3C Turtle 本体（RDF/OWL/SKOS/SWRL）。双模型异构质检 + 三级机械校验 + 黄金用例业务验收。

S0-S6 · G1-G3 人工闸门
2

ontology-review

建模产物 → 单文件 HTML 审阅页（类图 + 规则双通道 + 批注 UI）。业务专家零工程背景即可审阅，意见机械回流建模。

浏览器直开 · 零依赖
3

ontology-simulate

专家复核本体 → what-if 物化推演（画像→实例→Pellet 推理→业务解读）。三臂 A/B 实验量化形式化增量。

零臆造闸门 · 零回写沙箱

设计特点

载体中立适用金融、保险、供应链、制造等任何行业域。示例为虚构票据贴现载体。
双模型异构质检生成与审计必须由不同模型承担，禁止同模型自审。平台无关纪律。
人工闸门停等业务语义由人确认（G1-G3 / SG1-SG2 / AG1-AG2），LLM 不代答代签。
开放世界诚实未推出 ≠ 否定。信息不足时输出「未判定」，不伪装为通过或拒绝。
机械可验证T0-T12 统一验收电池，双跑字节确定性，零回写 hash 断言。
自包含方法论28 条建模判据焙入 methodology-core，脱离知识库可独立执行。

快速开始

# 1. 环境引导（检查 python3/pip/Java/node，安装依赖，跑验收）
bash scripts/bootstrap.sh --run-tests

# 2. 或单独跑验收电池（虚构示例载体为 fixture）
python3 scripts/run_suite_tests.py              # T0-T12, exit 0 = 全过
python3 scripts/run_suite_tests.py --skip-java  # 无 Java 环境（T8 登记 SKIP）

# 3. 统一 CLI 入口（机械 backbone 门面，LLM 编排外接）
python3 scripts/ontology_cli.py --help          # 能力地图：model / review / simulate / suite
python3 scripts/ontology_cli.py suite doctor    # 只读环境自检
python3 scripts/ontology_cli.py model validate examples/票据贴现/建模run/ontology.ttl
python3 scripts/ontology_cli.py model patch ontology.ttl patch.json --golden cases.json  # R2 增量 patch
python3 scripts/ontology_cli.py model shapes ontology.ttl --output-shapes shapes.ttl     # R4 TTL→SHACL 派生
python3 scripts/ontology_cli.py model shacl data.ttl shapes.ttl --strict                 # R4 实例级数据完整性校验

# 4. 浏览器打开示例审阅页（离线、零依赖）
open examples/票据贴现/建模run/审阅页.html

Claude Code 中触发：/ontology-model · /ontology-review · /ontology-simulate
独立部署：三 skill 保持同级（跨 skill 相对 import），ONTOLOGY_RUNS_ROOT 指向 run 目录。
统一 CLI 为薄分发门面——参数原样转发底层脚本、退出码透传、脚本行为零改变（仍可独立运行）。
